# Which Mod - Renewed

A Starsector mod. Every tooltip says which mod the thing comes from, or **Vanilla**:
ships, fighters, weapons, hull mods, ship systems, special items, blueprints, commodities,
industries, conditions, skills, abilities and terrain.

The mod name is the same one the game's codex shows. Blueprints and modspecs name the mod of the
ship, weapon, fighter, hull mod or industry they unlock.

Requires [PatchLib](https://github.com/Lukas22041/PatchLib). Starsector 0.98.5a.

Turn off WhichMod and Which-Industry when you use this mod, or those tooltips show the mod twice.
AoTD - Vaults of Knowledge has its own option for industries in its build menu filter.
